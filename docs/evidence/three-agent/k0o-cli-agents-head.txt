# Agent Instructions

This file is the **single portable agent instruction authority** for foundry-smoke-cli
(REQ-009). Target agents: **Grok Build** (primary), **Codex** and **Cursor**
(first-class secondary). Do not add vendor-specific instruction files
(`.claude/`, `CLAUDE.md`, Cursor rules that override this file, etc.).

## Canonical commands

Documented identically here, in `docs/commands.md`, and in Core CI
(`.github/workflows/ci.yml` / `strict.yml`). Always use direct Go tool
invocations (no task runner).

```bash
gofmt -l .                 # formatting check (CI); gofmt -w . to fix
go test -count=1 ./...     # uncached tests
go vet ./...
go tool staticcheck ./...
go tool govulncheck ./...  # scheduled/strict
go build ./...
```

Staticcheck and govulncheck are declared as Go `tool` directives in `go.mod`
with exact pinned versions.
